## Fix Details

### CR-01 — Delete-reorder rename loop atomic with rollback (`a504b09`)

`_delete_frame` and `_delete_song` now build a complete rename plan (list of `(src, dst)` pairs) before executing any filesystem operations. If any `os.rename` raises mid-loop, a best-effort rollback reverses completed renames in reverse order before re-raising. Prevents filesystem/manifest inconsistency from partial reorder failures.

### WR-01 — `_write_manifest_atomic` cleanup safe (`5aaca53`)

The `os.unlink(tmp_path)` cleanup call in the `except` branch of `_write_manifest_atomic` is now wrapped in `try/except OSError: pass`. A failure to delete the temp file no longer swallows the original exception.

### WR-02 — Upload size guard added (`94eca27`)

Added `MAX_FRAME_BYTES = 1 MB` and `MAX_SONG_BYTES = 64 KB` constants. Both upload endpoints call `await file.read(limit + 1)` and return HTTP 413 immediately if the payload exceeds the cap. Prevents memory exhaustion from unbounded uploads.

### WR-03 — `hashlib.md5` FIPS-safe (`470d4e5`)

Both `hashlib.md5(data)` calls in ETag generation now pass `usedforsecurity=False`. Compatible with Python 3.9+ and FIPS-enabled environments (though this is a homelab server, correctness is preserved).

### WR-04 — Test dependencies documented (`cc6ae6a`)

Added `requirements-dev.txt` with `pytest>=8.0` and `httpx>=0.27`. A fresh environment can now install and run the test suite without manual dependency resolution.

### WR-05 — Traceback preserved in `convert_png` (`076d19b`)

Replaced `except (ValueError, TypeError) as exc: raise exc` with `except (ValueError, TypeError): raise`. Bare `raise` preserves the original traceback location rather than replacing it with the re-raise site.
