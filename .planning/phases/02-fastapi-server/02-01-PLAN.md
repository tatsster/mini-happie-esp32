<objective>
Build the FastAPI application core for the happy-birthday-esp32 homelab server: the app object with a lifespan startup handler, module-level Path constants, atomic lock-guarded manifest persistence, the `GET /manifest.json` endpoint, and the two upload endpoints (`POST /upload/frame`, `POST /upload/song`) that call the Phase 1 converters and store assets to disk.

Purpose: This is the storage and ingestion half of the API. The ESP32 (and later the Phase 3 web UI) reads the manifest to discover assets and posts new frames/songs here. Without atomic, lock-guarded manifest writes, concurrent uploads silently lose entries (RESEARCH Pitfall 4).
Output: `server/main.py` (app + manifest helpers + manifest/upload endpoints) and an updated `server/requirements.txt`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → FastAPI | Untrusted upload bytes and form data cross here (ESP32, browser, curl) |
| FastAPI handler → local disk | Server writes attacker-influenced file content to data/frames and data/songs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | POST /upload/frame, POST /upload/song slot naming | mitigate | Slot name is server-generated (`f"frame_{idx}"` / `f"song_{idx}"`) from manifest length, never from client input — client cannot influence the written path |
| T-02-02 | Tampering | manifest read-modify-write under concurrency | mitigate | Entire read-modify-write wrapped in `threading.Lock` (`_manifest_lock`); atomic `os.replace` so a crash mid-write never corrupts manifest.json |
| T-02-03 | Denial of Service | POST /upload/* unbounded file size | accept | Homelab single-owner LAN, no public exposure (REQUIREMENTS.md excludes auth/public access). FastAPI/python-multipart impose no size cap; acceptable for v1. Documented in RESEARCH Security Domain |
| T-02-04 | Tampering / Info Disclosure | convert_png / convert_sheet on malformed input | mitigate | Converters raise ValueError on malformed input → caught and returned as HTTP 422; no stack trace leaked to client beyond the detail message |
| T-02-SC | Tampering | pip install fastapi/uvicorn/python-multipart | mitigate | RESEARCH Package Legitimacy Audit: all three slopcheck [OK] / Approved on PyPI; no [ASSUMED]/[SUS]/[SLOP] packages requiring a blocking checkpoint |
</threat_model>
